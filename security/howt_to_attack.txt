1. BRUTE FORCE ATTACK
==============================================================

Description
-----------
An attacker repeatedly attempts to log into the SAME account using
multiple incorrect passwords until the correct one is found.

Demo
----
Target Account:
john@example.com

Attempts:
Wrong Password 15 times

Time:
Within 1 minute

Example

10:00:01
john@example.com
abc123

10:00:04
john@example.com
pass123

10:00:08
john@example.com
hello123

...

Repeat until 15 failed attempts.

Detection
---------
• Same IP
• Same Account
• High number of failed logins

Nexora Response
---------------
✓ Detects Brute Force
✓ Calculates High Risk
✓ Blocks IP
✓ Logs Attack
✓ Sends Email Alert

Impact
------
• Account compromise
• Unauthorized access
• Service disruption
• Password guessing attack

5. PASSWORD SPRAYING
==============================================================

Description
-----------
An attacker tries one commonly used password across many different
accounts to avoid triggering account-specific lockouts.

Demo
----
Use ONE password such as:

Password123

Try it on:

john@example.com

↓

doctor@example.com

↓

manager@example.com

↓

admin@example.com

↓

user@example.com

Maximum:
3 attempts per account

Time:
Within 15 Minutes

Detection
---------
• Same IP
• Many accounts
• Low attempts per account

Nexora Response
---------------
✓ Detects Password Spraying
✓ Calculates Risk
✓ Blocks IP
✓ Logs Threat
✓ Sends Email Alert

Impact
------
• Weak password compromise
• Large-scale account takeover
• Organizational security risk
